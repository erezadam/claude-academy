## מה זה Claude Code — ומתי הוא לא הכלי הנכון

Claude Code הוא סוכן קוד שרץ אצלך במחשב: הוא קורא את הקבצים של הפרויקט, עורך אותם, מריץ פקודות בטרמינל, ומחזיר לך תוצאה — לא הסבר על תוצאה. זה ההבדל המהותי מצ'אט.

## מה הוא עושה בפועל

אתה פותח אותו בתוך תיקיית פרויקט, כותב בעברית או באנגלית מה אתה רוצה, והוא עובד: מאתר את הקבצים הרלוונטיים, משנה אותם, מריץ בדיקות אם ביקשת, ומראה לך מה השתנה. הוא מבין את הפרויקט כולו — לא רק את הקטע שהדבקת לו.

```
תוסיף כפתור התנתקות לעמוד ההגדרות
```

זה כל מה שצריך לכתוב. הוא ימצא לבד את עמוד ההגדרות.

## במה זה שונה מצ'אט רגיל

| צ'אט | Claude Code |
|---|---|
| אתה מדביק קוד, הוא מחזיר קוד | הוא קורא את הפרויקט בעצמו |
| ההעתקה חזרה — עליך | הוא עורך את הקבצים ישירות |
| לא נוגע בסביבה שלך | מריץ פקודות, בדיקות ו-build אצלך בפרויקט |
| ההקשר נגמר עם השיחה | זוכר את הפרויקט בין סשנים (CLAUDE.md) |

## מתי הוא לא הכלי הנכון

שלושה מצבים שבהם עדיף משהו אחר:

**כשאין לך פרויקט.** שאלה כללית ("מה ההבדל בין REST ל-GraphQL?") לא צריכה סוכן עם גישה לקבצים — צ'אט רגיל מהיר וזול יותר.

**כשאתה לא מוכן שמשהו ישתנה.** הכלי נועד לערוך קבצים ולהריץ פקודות. אם אתה רק רוצה לקרוא ולהבין קוד רגיש בלי לגעת — אפשר, אבל צריך להכיר קודם את מנגנון ההרשאות. אל תתחיל שם.

**כשאתה מצפה שהוא יחליף אותך.** הוא מצוין בביצוע, בינוני בלנחש מה רצית. בקשה מעורפלת מייצרת תוצאה מעורפלת — ולכן המאמר השלישי במסלול הזה עוסק כולו באיך לנסח בקשות.

## מה הלאה

מתקינים ומריצים סשן ראשון — זה הצעד הבא במסלול.
