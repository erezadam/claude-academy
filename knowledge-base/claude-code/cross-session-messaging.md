Cross-session messaging מאפשר ל-Claude בסשן אחד לשלוח הודעה ל-Claude בסשן אחר. כשסשן אחד מגלה ממצא שמשפיע על עבודה בסשן אחר, Claude יכול להעביר את המידע ישירות — בלי שתעתיקו בין טרמינלים.

## מה זה עושה / למה זה שימושי

Claude משתמש בשני כלים: `ListAgents` לגילוי הסשנים שניתן להגיע אליהם, ו-`SendMessage` לשליחת הודעה לאחד מהם. אתם לא קוראים לכלים האלה ישירות — Claude עושה זאת בעצמו כשהוא רואה צורך, או כשתבקשו ממנו.

מצבי שימוש טיפוסיים:

- **העברת ממצא** — סשן אחד מגלה breaking change; Claude מסכם אותו לסשן שעובד על הקוד המושפע
- **תיאום worktrees מקבילים** — כשסשנים עובדים על אותו repository בסניפים שונים, Claude מודיע מה נוחת
- **קבלת סטטוס מ-migration ממושך** — הסשן שרץ ברקע מדווח אל הסשן שאתם צופים בו
- **מענה בין מכשירים** — תשובה להודעה שהגיעה מסשן על מחשב אחר דרך Remote Control

הפעלה דורשת Claude Code v2.1.224 ומעלה, ועובדת על macOS ו-Linux.

## איך משתמשים

פשוט הסבירו ל-Claude מה אתם רוצים שיגיע לסשן השני:

```text
שאל את הסשן שרץ בטרמינל השני אם ה-migration הסתיים
```

```text
הסבר לסשן שעובד על ה-payments API מה עשינו עכשיו
```

Claude כותב את ההודעה בעצמו. לפעמים הוא ישלח ביוזמתו, בלי שתבקשו, כשהוא מזהה שסשן אחר זקוק למידע.

**@-mention ישיר של סשן** (דורש v2.1.232): כדי לנקוב בסשן יעד ספציפי, הקלידו `@` ואחריו האותיות הראשונות של שמו ובחרו מה-typeahead — בדיוק כמו @-mention של subagent. Claude Code מוסיף את ה-mention (למשל `@api-worker`) ומעביר ל-Claude את הסשן שהמention מייצג, כך שClaude יכול לשלוח אליו ישירות בלי לרשום קודם את כל הסשנים.

```text
אמור ל-@api-worker שהmigration של הschema הסתיים
```

`SendMessage` עכשיו מעביר לשם חשוף שמתאים בדיוק לסשן אחד פעיל, בלי לבקש אישור קודם.

לראות אילו סשנים Claude יכול להגיע אליהם:

```text
/list-agents
```

הפקודה מציגה כל סשן עם השם שהוא עונה לו. סשן עונה לשם שהוגדר ב-`/rename` או בדגל `--name`; ללא הגדרה, Claude Code מייצר שם אוטומטי כמו `myapp-3f`.

**שמות ייחודיים על אותו מחשב** (v2.1.232): כשמתחילים או משנים שם סשן לשם שסשן אחר פעיל כבר משתמש בו — Claude Code משאיר את השם אצל הסשן שכבר מחזיק בו ומשנה את שמכם לוריאנט (למשל `name-word-word`).

## משלוח הודעה והתוצאה האפשרית

כשהודעה מגיעה לסשן, Claude Code בוחן אותה ומחליט:

| תוצאה | משמעות |
|:--|:--|
| Delivered | ההודעה הועברת ל-Claude של הסשן המקבל |
| Held | ההודעה הוחזקה ממתינה לאישורכם |
| Refused | ההודעה נפלה ולא הועברה |

ברירת המחדל תלויה במצבי ההרשאות של שני הסשנים. סשן שמאשר פעולות בעצמו (bypass permissions) יחזיק הודעות נכנסות לאישורכם. סשן רגיל יקבל הודעות מסשנים רגילים. ניתן לשלוט בהתנהגות עם הגדרת `crossSessionInbound`:

| ערך | התנהגות |
|:--|:--|
| `accept` | כל הודעה מועברת ל-Claude |
| `hold` | כל הודעה מוחזקת ממתינה לאישורכם |
| `refuse` | כל הודעה נפלת |

מ-v2.1.232 אפשר לבחור את הערך גם דרך `/config` בשורה **Messages from your other sessions** — Claude Code כותב את הערך שתבחרו להגדרות המשתמש.

**זמן תפוגה לdialog**: ההגדרה `dialogExpiry` קובעת כמה זמן (בדקות) dialog אישור נשאר פתוח לפני שההודעה נמחקת. ברירת המחדל היא 5 דקות. ניתן לקנפג גם דרך `/config` בשורה **Dialog expiry**. ערך `"never"` שומר הודעות עד סיום הsession.

## הגבלות על הודעות נכנסות

כשהודעה מגיעה מסשן אחר, Claude Code מגביל מה היא יכולה לעשות:

- **לא מאשרת פעולות** — הודעה מסשן אחר לא נחשבת הסכמתכם ואינה עונה על שאלות הרשאה
- **לא משנה הגדרות** — Claude Code מנחה את הסשן המקבל לא לשנות הרשאות, CLAUDE.md או הגדרות אחרות
- **פקודות לא מופעלות** — פקודה כמו `/compact` בתוך ההודעה מגיעה כטקסט רגיל

## הודעות בין מכשירים

| מיקום הסשן המקבל | כיצד ההודעה מועברת |
|:--|:--|
| על אותו מחשב | דרך socket מקומי, לא עובר דרך שרתי Anthropic |
| על מחשב אחר שלך | דרך שרתי Anthropic, מגיע דרך חיבור Remote Control של אותו מחשב |
| Claude Code on the web | דרך שרתי Anthropic, ישירות לסשן הענן |

**שליחת הודעה לסשן על מחשב אחר** (דורש v2.1.225): Claude יכול גם **להתחיל** שיחה עם סשן על מחשב אחר שלך — לא רק להשיב. הסשן המרוחק צריך להופיע ברשימת `/list-agents`.

לפני v2.1.225, Claude יכול היה רק להשיב להודעה שהגיעה ממחשב אחר.

```text
/list-agents
```

הרשימה מציגה סשנים מקומיים ובנוסף, כש-Remote Control מחובר: סשנים על מחשבים אחרים (מסומנים `Remote Control`) וסשני ענן (מסומנים `cloud`). סשן Remote Control שניתוק הremoте Control connection שלו מסומן `offline`.
