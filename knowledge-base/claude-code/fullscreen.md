מצב מסך מלא (Fullscreen Rendering) הוא נתיב רינדור חלופי ל-CLI של Claude Code שמסלק ריצוד, שומר על שימוש קבוע בזיכרון לאורך שיחות ארוכות, ומוסיף תמיכה בעכבר. הוא מצייר את הממשק על ה-alternate screen buffer של הטרמינל, כמו `vim` או `htop`, ומרנדר רק הודעות שנמצאות כרגע בתצוגה.

## מה זה עושה / למה זה שימושי

ההבדל בולט במיוחד בטרמינלים שבהם מהירות הרינדור מגבילה — כגון VS Code terminal משולב, tmux ו-iTerm2. אם מיקום הגלילה קופץ לראש המסך כשקלוד עובד, או שהמסך מהבהב בזמן זרימת פלט, המצב הזה פותר את הבעיה.

מאחר שרק ההודעות הנראות ברגע נשמרות בעץ הרינדור, שימוש הזיכרון נשאר קבוע גם בשיחות ארוכות מאוד.

## איך משתמשים

### הפעלה

```text
/tui fullscreen
```

ה-CLI שומר את ההגדרה ומאתחל מחדש עם השיחה שלמה — ניתן לעבור באמצע שיחה בלי לאבד הקשר. לחזרה לרינדור הרגיל:

```text
/tui default
```

לבדיקת הגדרה פעילה:

```text
/tui
```

ניתן גם להגדיר משתנה סביבה לפני ההפעלה:

```bash
CLAUDE_CODE_NO_FLICKER=1 claude
```

### מה משתנה

בניגוד לרינדור הרגיל, תיבת הקלט נשארת קבועה בתחתית המסך בזמן שקלוד עובד. הגלילה עוברת מה-scrollback של הטרמינל לפקד פנימי — גלול עם גלגל העכבר או PageUp/PageDown בתוך Claude Code.

| לפני (רינדור רגיל) | עכשיו (מסך מלא) |
| :--- | :--- |
| `Cmd+F` או חיפוש tmux | `Ctrl+O` לצפיית transcript, ואז `/` לחיפוש |
| בחירה-גרירה מקורית של הטרמינל | בחירה פנימית, מועתקת אוטומטית בשחרור |
| `Cmd`-click לפתיחת URL | `Cmd`-click ב-macOS, `Ctrl`-click בשאר |

### ניווט וחיפוש בשיחה

לחץ `Ctrl+O` לפתיחת תצוגת transcript. בתוכה:

- `/` לחיפוש טקסט בשיחה
- `[` להעתקת השיחה ל-scrollback של הטרמינל לחיפוש עם `Cmd+F` של הטרמינל

### שימוש בעכבר

מצב מסך מלא לוכד אירועי עכבר:

- **לחיצה על תיבת הקלט** — ממקמת את הסמן בנקודה שנבחרה
- **לחיצה על הצעה** בתפריט `/` או `@` — מקבלת אותה
- **לחיצה על אפשרות** בדיאלוג (`/model`, `/config` וכד') — בוחרת אותה
- **לחיצה על תוצאת כלי מקופלת** — מרחיבה את הפלט המלא; לחיצה שנייה מקפלת
- **Cmd/Ctrl + לחיצה על URL או נתיב קובץ** — פותח בדפדפן או אפליקציה מתאימה

## ברירת מחדל — מתי מצב מסך מלא מופעל

Claude Code קובע את הרינדור לפי הרצף הבא (עצירה בהתאמה ראשונה):

| מצב | רינדור |
| :--- | :--- |
| `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` מוגדר | קלאסי |
| `CLAUDE_CODE_NO_FLICKER=1` מוגדר | מסך מלא |
| גרסה 2.1.239+ ללא fetch של feature flags (Bedrock, Vertex, Foundry, telemetry כבוי) | מסך מלא |
| המשתמש הצטרף ל-Claude Code מה-6 במאי 2026 ואילך (עם feature flags) | מסך מלא |
| ברירת מחדל | קלאסי |

כשנשמרת הגדרת `tui` בקובץ ההגדרות, היא גוברת על הטבלה למעט שתי השורות הראשונות.
